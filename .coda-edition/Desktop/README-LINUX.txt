CodaLauncher · Coda Edition — Linux x64

Extract the separate archive and run ./start.sh on a graphical desktop.
Keep all files together. The .NET runtime is bundled.

Your original launcher and worlds are not imported or changed. This edition
uses .howlingwhispers-coda-edition under the OS ApplicationData directory.
Minecraft needs Java 25+; installing and launching uses the existing verified
content preparation and official launcher handoff.

See README-CODA-EDITION.md for requirements and validated capabilities.
