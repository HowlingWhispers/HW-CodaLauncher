CodaLauncher 0.6.0 • Linux

Extract the complete archive into its own folder and run ./start.sh.
Keep all files together. The .NET runtime is included.

Minecraft requires Java 25 or newer on PATH.
PLAY prepares CodaLoader, HW Essentials and CML Base Resources automatically.

Requires a graphical desktop with X11 or XWayland, fontconfig, libX11,
libICE and libSM. On Debian/Ubuntu the GUI packages are typically:
libx11-6 libice6 libsm6 libfontconfig1

This is a desktop client, not a headless Minecraft server application.
The Linux ARM64 download requires an ARM64 system and ARM64 Java.

Launcher update notifications link to the appropriate new download.
Extract a newer launcher into its own folder. Worlds, mods and settings
live in the user's ApplicationData/.howlingshispers folder, outside the app.
